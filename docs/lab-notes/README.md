# Lab Notes — 실험 전환점 기록

가설이 반증되거나, 예상 밖 병목이 발견되거나, 계획이 꺾이는 순간을 **그 자리에서** 기록한다.
마일스톤 요약(커밋 메시지, reports/)과 달리, 여기엔 "왜 방향을 바꿨는가"의 추론 과정을 남긴다.

## 기록 시점 (트리거)

- 실측이 문서/리서치의 예상 수치와 어긋날 때
- 실험이 null result로 끝날 때 (가장 중요 — 커밋 로그에 묻히기 쉽다)
- 가설·로드맵·설계를 변경할 때
- 원인 규명에 트레이스/데이터를 쓴 디버깅이 끝났을 때

## 형식

`NNN-제목.md`, 각 노트는 다섯 절:

```
# NNN. 제목
- 날짜 / 관련 마일스톤 / 관련 커밋
## 상황     — 무엇을 하다가
## 증거     — 어떤 데이터가 (트레이스 run_id, 수치, 재현 커맨드)
## 해석     — 왜 그런가
## 결정     — 그래서 뭘 바꾸나
## 영향     — 로드맵/설계/문서에 미치는 것
```
